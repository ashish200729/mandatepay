# Self-hosted fonts

The active font pairing matches the families identified in Runable's public marketing stylesheet:

- **Hedvig Letters Serif** for editorial headings, obtained from Google Fonts under the SIL Open Font License. See `HEDVIG-LETTERS-SERIF-LICENSE.txt`.
- **Satoshi Variable** for body copy and controls, obtained from the official Fontshare download under the ITF Free Font License. See `SATOSHI-LICENSE.txt`. These files are used for MandatePay's own website and application, not as a user-selectable font service.

Both fonts are served locally with `next/font/local`. No runtime requests go to Google Fonts or Fontshare. Original Geist and Instrument Serif assets and their licenses remain here from the first foundation version; they are no longer referenced by the application.

- Geist: https://github.com/google/fonts/tree/main/ofl/geist
- Instrument Serif: https://github.com/google/fonts/tree/main/ofl/instrumentserif
- Hedvig Letters Serif: https://github.com/google/fonts/tree/main/ofl/hedviglettersserif
- Satoshi: https://www.fontshare.com/fonts/satoshi
