# Dashboard surface

Mode: Operate. Authenticated users inspect purchasing permissions, transaction decisions, verified payment records, and blocked attempts. Preserve all existing API contracts and financial actions. The approved landing page remains the visual authority.

## Direction contract

THESIS: A calm purchasing ledger. Summary, query, records, analysis, and policy history form one readable sequence.

OWN-WORLD: Warm ivory workspace, sand navigation selection, white ledger, fine warm borders. Hedvig page headings; Satoshi controls, data, and section titles.

STORY: Understand current activity, filter it, then open the exact record and audit trail.

FIRST VIEWPORT: A 232px desktop sidebar and 72px utility bar frame a 40px title. A divided summary band leads into one transaction section with labeled query and filters. Primary navigation remains quiet.

FORM: Task-led ledger within the established brand; direct user-requested redesign, no concept seed. Mobile replaces wide records with complete stacked summaries and a compact navigation panel.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
